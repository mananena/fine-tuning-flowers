# Flowers: подвыборка из открытого набора

Задача: различать daisy (маргаритки), roses (розы), sunflowers (подсолнухи).
Для каждого класса взято 60 фотографий, всего 180. Снимки скачаны из набора
TensorFlow Flowers, а не сделаны автором работы. Это отклонение от требования
лабораторной о самостоятельной съёмке, которое нужно согласовать с преподавателем.

Источник: https://www.tensorflow.org/tutorials/load_data/images
Архив: https://storage.googleapis.com/download.tensorflow.org/example_images/flower_photos.tgz
В исходном архиве 3670 фотографий пяти классов; используются три из них.
Дата загрузки: 11 октября 2026 года. Отбор: сортировка исходных имён, shuffle
с seed=42, первые 60 уникальных файлов каждого класса. Исходные имена сохранены.
Авторы, исходные ссылки и лицензии CC BY сохранены в LICENSE.flowers.txt.
manifest.json содержит происхождение и SHA-256 каждого выбранного файла.

Фотографии сохранены без изменений, проверены на читаемость и точные дубликаты.
При обучении применяется стратифицированное разбиение 42/9/9 на класс:
126 train, 27 validation, 27 test. Риск близких кадров из одной серии полностью
не исключён: метаданные объектов отсутствуют, это ограничение оценки.

Предобработка: EXIF orientation, RGB, bicubic resize, center crop до 160x160,
нормализация mean/std выбранной предобученной модели. Для train вместо
центрального crop используется случайный resized crop, отражение, поворот
до 10 градусов и умеренный ColorJitter. Оценка и ONNX используют одну функцию.
