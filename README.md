# Fine-Tuning: классификация собственных фотографий

Проект для лабораторной: сравнение ResNet18 и MobileNetV3 Small, подбор скорости
обучения, оценка ошибок, экспорт выбранной модели в ONNX и локальное приложение.

**Текущий статус:** подготовлена подвыборка Flowers: 3 класса по 60 снимков.
Это открытые фотографии, а не самостоятельная съёмка; данный пункт задания
не выполнен. Обучение и экспорт пока не выполнялись, численные результаты
не подставлены.

## Структура

```text
experiments/
  data/raw/                 # свои фотографии по папкам классов
  data/README.md            # описание сбора
  notebooks/experiments.ipynb
  train.py                  # dataclass, обучение, выбор и экспорт
  preprocessing.py          # общая предобработка
  runs/                     # split, конфигурации, логи и графики
  models/                   # выбранная модель ONNX и метаданные
app/
  app.py                    # Gradio + ONNX Runtime CPU
  requirements.txt          # лёгкое окружение приложения
requirements.txt
```

## Установка (Windows, Python 3.11)

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
jupyter lab
```

Первый запуск обучения скачивает предобученные веса и требует интернет.
Зависимости зафиксированы по версиям, но установка в текущей среде не проверена.
Для CPU подходят модели малого размера; базовый размер входа 160 вместо 224
уменьшает вычисления и может снизить качество. Для CUDA установите совместимую
с драйвером сборку PyTorch. Все команды запускайте из корня проекта.

## Данные и эксперименты

1. Добавьте минимум 30 своих изображений в каждую из трёх папок классов в
   `experiments/data/raw/`. Заполните описание реального сбора в `data/README.md`.
2. Откройте ноутбук и выполните ячейки по порядку. Он запускает четыре эксперимента:
   две архитектуры × две скорости обучения, одинаковый seed и общий сплит.
3. Две первые эпохи обучается только классификатор. Затем размораживается вся
   модель с меньшей скоростью для backbone. AdamW, weight decay и cosine scheduler
   задаются в коде; параметры сгруппированы в `TrainConfig`.
4. Выбор лучших гиперпараметров выполняется по validation accuracy. При равенстве
   используется первый запуск в алфавитном порядке. После выбора тестируются
   лучшие варианты каждого семейства и экспортируется общий победитель.
5. Изучите кривые, матрицы ошибок и неверно классифицированные фотографии.
   Допишите в ноутбуке собственную интерпретацию фактических результатов.

Один запуск вручную:

```powershell
python -m experiments.train --model resnet18.a1_in1k --run-name resnet_lr001 --lr 0.001
python -m experiments.train --model mobilenetv3_small_100.lamb_in1k --run-name mobile_lr001 --lr 0.001
python -m experiments.train --finalize
python -m app.app
```

Сервер Gradio запускается локально, ссылка выводится в терминале. Дополнительное
окружение приложения можно установить из `app/requirements.txt`; PyTorch ему
не нужен. Функция предобработки общая с оценкой модели. Экспорт проверяется
ONNX checker и сравнением logits/классов PyTorch и ONNX на тестовых изображениях.
Размер входа ONNX фиксирован: один снимок, три канала, размер из метаданных.

## Воспроизводимость и результаты

Фиксируются Python random, NumPy, PyTorch, CUDA и DataLoader. Включены
детерминированные операции; между разными устройствами идентичные числа
не гарантируются. Сохраняются конфигурация, версии PyTorch/timm, split с хешами,
история каждой эпохи, лучший checkpoint и длительность обучения.

Не запускайте повторный подбор после просмотра test accuracy: иначе test
перестанет быть независимой оценкой. Для нового набора используйте другую папку
`--runs`; при изменении данных сохранённый split отклоняется.

Для сдачи нужно добавить реальные результаты, выполненный notebook, графики
и описание собственного датасета, затем создать публичный репозиторий GitHub.
Большие .pt/.onnx лучше разместить в GitHub Release или Git LFS и указать ссылки.
Подвыборка фотографий включена в проект вместе с исходными лицензиями. Ссылку на репозиторий прикрепите в LMS.
